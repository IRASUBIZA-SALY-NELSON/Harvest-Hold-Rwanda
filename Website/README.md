# Harvest Hold Rwanda

Professional website for Harvest Hold Rwanda — an IoT and AI AgTech initiative reducing post-harvest losses with affordable, solar-powered charcoal cooling and a digital marketplace.

## Stack

- React 19 + Vite
- Tailwind CSS v4
- Google Fonts: **Fraunces** (display) + **Sora** (body)

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```
