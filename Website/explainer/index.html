Harvest Hold Rwanda Prototype walkthrough
01 · Overview

How the Smart Hybrid Charcoal Cooler works

A low-cost, solar-powered evaporative cooler with IoT monitoring — built so you can prototype it before scaling to village silos.

  • Double-walled crate + wet charcoal = 10–15°C cooling
  • ESP32 brain controls fan, pump, and alerts
  • Dashboard logs become market quality proof
02 · Cooling physics

Evaporative cooling cycle

Water wets the charcoal. The fan pulls warm air through it. Evaporation pulls heat out — cooled air enters the produce chamber.

  • Reservoir slowly wets the ~10 cm charcoal bed
  • 5V DC fan drives airflow through wet charcoal
  • Chamber typically drops 10–15°C below ambient
03 · Digital brain

ESP32 sensing & control

The microcontroller closes the loop: sense → decide → actuate → alert → sync.

  • SHT31 (I²C) monitors chamber T/H
  • Ethylene sensor tracks ripening gas
  • ESP32 toggles pump & fan for efficiency
  • OLED shows live status; GPIO alerts on breach
04 · Dashboard

From silo to marketplace

Wi-Fi/MQTT streams data to a cloud dashboard — this is where long-term commercial value compounds.

  • Live temperature, humidity, ethylene
  • Automated alerts / SMS on breaches
  • Downloadable quality certificates
  • Fleet view for cooperative multi-unit ops
05 · Build checklist

Your first prototype path

Use this sequence when you start fabrication and wiring.

  • Build double-walled crate (~10 cm gap) + charcoal fill
  • Add reservoir wetting path + 5V DC fan
  • Wire ESP32, SHT31, OLED on I²C (21/22)
  • Power: solar + TP4056 + 3.7V LiPo → 5V
  • Alerts on GPIO17/19 · MQTT to dashboard
